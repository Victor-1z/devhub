DevHub – Plataforma de Estudos de Programação

Sobre o projeto

O DevHub é uma aplicação web desenvolvida com o objetivo de apresentar cursos e conteúdos relacionados à programação e tecnologia.

A plataforma foi criada para estudantes e pessoas que desejam iniciar seus estudos na área de desenvolvimento de software.

O projeto foi desenvolvido como atividade acadêmica, aplicando conceitos de desenvolvimento frontend, componentização, manipulação de dados e navegação SPA.

Interface responsiva.

Justificativa da escolha do framework

O Vue.js foi escolhido por ser um framework JavaScript progressivo, que permite desenvolver interfaces dinâmicas por meio de componentes reutilizáveis.

Sua estrutura facilita a organização do código, a manipulação de estados e a implementação de eventos e funcionalidades interativas.

Além disso, sua integração com o Vite e o Vue Router permite desenvolver aplicações SPA de maneira organizada e eficiente.

Como executar o projeto

Pré-requisitos

Node.js instalado.

npm instalado.

Git instalado.

Instalação

Clone o repositório:

git clone https://github.com/Victor-1z/devhub.git

Entre na pasta:

cd devhub

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Acesse o endereço apresentado no terminal.

Compilação

Para gerar a versão de produção:

npm run build
